# Third-party and provenance notes

This package is an independently written reference implementation.

It was architecturally informed by the public G-Memory paper and repository:

- G-Memory paper: <https://arxiv.org/abs/2506.07398>
- Official repository: <https://github.com/bingreeky/GMemory>
- Reviewed revision: `7b581c51d993bd600df14691d101d7e601040cc6`

No G-Memory source code, prompt text, data, or generated artifacts are included. At the reviewed revision, no license file was observed in that repository; direct source copying should therefore be avoided unless the authors provide an applicable license or explicit permission.

The bundled example Chips are synthetic and use `example.org` source URLs. They are tests and demonstrations, not empirical evidence.

The real paper Chips in the parent repository are not copied into this package or its ZIP. Users point the engine at those banks at runtime.
